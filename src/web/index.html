Como integrar no seu projeto

1. Aponte o client SMTP

Configure o envio de email da sua aplicação para este servidor, sem usuário, senha ou TLS:

SMTP_HOST=localhost
SMTP_PORT=1025

Exemplo com Nodemailer:

const transporter = nodemailer.createTransport({
  host: 'localhost',
  port: 1025,
  secure: false,
});

2. Se sua aplicação também roda em Docker

localhost não funciona de container para container. Coloque os dois serviços na mesma rede externa mailnet e aponte para o nome do serviço, não para localhost:

environment:
  SMTP_HOST: smdev
  SMTP_PORT: 1025
networks:
  - mailnet

3. Leia os emails pela API (opcional)

Útil em testes automatizados que precisam pegar um código de verificação sem abrir esta tela. CORS liberado — funciona direto do navegador ou do lado do servidor.

GET http://localhost:8025/api/messages/latest?to=<email>

Retorna a mensagem mais recente enviada a esse destinatário, incluindo o campo otp quando um código é detectado.

Referência completa da API e mais exemplos (Python, PHP) em docs/api-reference.md e docs/integration.md, no repositório do smdev.
